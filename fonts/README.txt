FONT FILES TO ADD HERE (the site already points to these exact names)
=====================================================================
Aeromatics  (main hero title  "Découvrez nos récents projets...")
   Aeromatics.woff2   (or .woff / .ttf / .otf)

Averta  (all other text: menus, headings, paragraphs, buttons, forms)
   Averta-Regular.woff2      (400)
   Averta-Semibold.woff2     (600)
   Averta-Bold.woff2         (700)
   Averta-ExtraBold.woff2    (800)
   (.woff / .ttf / .otf also work — same names)

If the fonts are installed on the computer, the browser uses them directly.
Until the files are here the site falls back to Archivo / Inter.
To use Aeromatics on other titles, use font-family: var(--font-display);
Check each font's licence allows web use before publishing.
